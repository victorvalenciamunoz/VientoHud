Respuestas reales de EUMETNET Open Radar Data (`https://s3.waw3-1.cloudferro.com/`, sin clave, CC BY 4.0),
grabadas el 2026-10-16 (fase 4, paso 4b-1). Son compuestos de toda Europa: los tests leen recortes alrededor de
puntos inventados.

- `OPERA@20261003T0600@0@DBZH.h5`: reflectividad máxima (CIRRUS), 1 km, toda Europa, del bucket `openradar-archive`.
- `OPERA@20261003T0530@0@RATE.h5` y `OPERA@20261003T0600@0@RATE.h5`: intensidad de lluvia (mm/h), 2 km, toda Europa.
- `list-24h-*.xml`: listados S3 del bucket `openradar-24h` (los ficheros de las últimas 24 horas).
- `missing-key.xml`: la respuesta S3 a un fichero que no existe.
